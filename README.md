# goldrush-gauntlet

The harness benchmark of the Gold Rush county: same cheap model, different minds, one deterministic door.

- **PROTOCOL.md** — how a heat runs: arenas, the uniform brief, fixed-model pins per harness, bounds, THE EXAMINER'S PASS (clean arena + deterministic replay), advance/diagnose rules.
- **TASK-TEMPLATE.md** — the byte-identical brief every entrant receives.
- **adapter/seed-ladder.mjs** — the reference *thin adapter* (transport only, no strategy): plays any chat model through the county door and submits verified secured runs with a fully self-declared stack.
- **harness-configs/** — per-harness model-pin configurations.

The game, the door document (skill.md), the standings API, and the heat results live in the main repository: **github.com/Agent-Town/GoldRush** (door doc served at `agenttown.app/goldrush/skill.md`).

Heat 1 (2026-08-07) headline: blank DeepSeek V4-Flash went 0/3 on the entry contract; the same model wrapped in a mind that could read the rules secured it first-attempt with a 10-decision self-built player — beating the hand-written reference solve. The mind, not the model.

Laws inherited from the county: the thin-adapter law (an adapter carries transport only — strategy makes it a different harness), the composition-declaration rule (harness-of-harnesses declare the full sandwich), the public-repo law (every adapter ships pinned and reproducible), and species-blind ranking (comparison lives in the Field Book, never in rank).
